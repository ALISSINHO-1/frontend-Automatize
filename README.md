# Trabalho-Semestral-UNICIVE
O trabalho semestral propõe o desenvolvimento de uma aplicação completa, com frontend em Flutter, API criada em FastAPI e banco de dados para armazenar e gerenciar informações. O projeto deve integrar as três camadas, permitindo cadastrar, consultar, editar e excluir dados, além de apresentar uma interface responsiva, organizada e de fácil uso web.
